# מערכת ניהול ותחזוקת נכסים

מערכת למעקב אחר נכסים (דירות), ביצוע בדיקות תקופתיות (מרחוק / בד"ח מקומי), תזכורות, שמירת טיוטות באמצע בדיקה, וייצוא דו"ח בדיקה רשמי לקובץ Word.

הפרויקט מורכב משני חלקים:
- `apartment-manager` — צד לקוח (React + Vite)
- `apartment-server` — שרת API (Node.js + Express + PostgreSQL)

## דרישות מקדימות

לפני שמתחילים, צריך שיהיו מותקנים על המחשב:
- **Node.js** (גרסה 18 ומעלה) — כולל npm. אפשר לבדוק עם `node -v`.
- **PostgreSQL** מותקן ופעיל, עם מסד נתונים ריק שנוצר עבור הפרויקט.

## שלב 1: שכפול הפרויקט

```
git clone https://github.com/inon-cohen/adas.git
cd adas
```

## שלב 2: הגדרת השרת (apartment-server)

```
cd apartment-server
npm install
```

יוצרים קובץ בשם `.env` בתוך תיקיית `apartment-server` (הוא לא נמצא בגיט מסיבות אבטחה — הוא מכיל פרטי חיבור למסד הנתונים). אפשר להעתיק את `.env.example` שנמצא באותה תיקייה ולמלא את הפרטים האמיתיים:

```
DATABASE_URL=postgresql://USERNAME:PASSWORD@localhost:5432/DATABASE_NAME
PORT=5000
```

לאחר מכן, יוצרים את הטבלאות במסד הנתונים על ידי הרצת קובץ הסכמה `schema.sql` (למשל עם `psql`, או דרך כלי ניהול כמו pgAdmin):

```
psql "postgresql://USERNAME:PASSWORD@localhost:5432/DATABASE_NAME" -f schema.sql
```

הרצת השרת (מריצה גם מיגרציות נוספות אוטומטית, ומוודאת שהכל מעודכן):

```
npm run dev
```

השרת יעלה כברירת מחדל על פורט 5000.

## שלב 3: הגדרת הלקוח (apartment-manager)

בטרמינל נפרד:

```
cd apartment-manager
npm install
npm run dev
```

Vite יפתח שרת פיתוח (בדרך כלל בכתובת `http://localhost:5173`) — זו הכתובת שנכנסים אליה בדפדפן. חשוב שהשרת (שלב 2) יהיה פעיל במקביל, כי הלקוח פונה אליו בכתובת `http://localhost:5000`.

## הערות

- `node_modules` לא נמצאות בגיט בכוונה (נוצרות מחדש עם `npm install`).
- קובץ `.env` לא נמצא בגיט בכוונה, כי הוא מכיל סודות (פרטי חיבור למסד הנתונים). כל מי שמוריד את הפרויקט צריך ליצור לעצמו קובץ כזה.
- `schema.sql` הוא שחזור של מבנה הטבלאות על סמך השאילתות בקוד השרת — אם יש לך כבר מסד נתונים קיים עם הנתונים, אין צורך להריץ אותו שוב (הוא כתוב כך שלא יפגע בטבלאות קיימות).
